# {{KIT_REPO}} — 전역 정책 (hot tier)

여기엔 **매번 참인 짧은 규칙만** 둔다. 절차는 `backbone/`, 지식은 `skills/`, 상황별 규칙은 `scopes/`.

> 판별: **한 영역(scope)이라도 반례가 있으면 전역이 아니다** → `scopes/`로. (결정 #11)

## 진입 — 모든 요청은 백본을 거친다

명시 명령어(`/tr:do`)는 **없다.** 훅이 상태를 주입하고, 「진입」이 판정한다.

```
「진입」  ⓪ 백본을 탈 일인가?   휘발("이 파일 뭐야")이면 안 탄다. 애매하면 가볍게 시작(lazy)
          ① 어느 profile인가?   애매하면 묻는다
          ② 어느 skill을 소환하나?
```

단계 정의 = `backbone/stages.md` · profile = `backbone/profiles/`.

## 우선순위 — **두 축이고 규칙이 다르다**

```
스킬 선택:  ①프로젝트 지정(repo {{AGENT_FILE}}) > ②{{KIT_REPO}} > ③외부(odin 등)
            ↑ 순서. 구체적인 게 이긴다. 같은 일이면 내 것 먼저

정책·가드:  회사 ∪ 프로젝트 ∪ 전역
            ↑ 합집합. 하나라도 금지하면 금지 — 우선순위로 뒤집지 않는다
```

## 항상 참인 것

- **응답 언어: 기본 한국어.** (영어로 요청할 때만 영어)
- **커밋 메시지: 한 줄 Conventional Commits 제목만.** 본문·Co-Authored-By 트레일러 없음.
- **안전 가드**: 되돌리기 어렵거나(삭제·덮어쓰기·force push·배포) **외부로 나가는**(push·전송·원격 실행) 액션은 **실행 전 확인**. 원격/서버 명령·의존성·secret 다루는 변경은 **report-first**(계획 먼저→확인). 이미 승인·지시된 건 진행.
  - 이건 **게이트가 아니라 L3 정책**이다 — 단계 진입이 아니라 **액션**을 막는다.
- **사실·근거 중시**: 단정적 주장·수치·고유명사엔 **근거/출처**를, **추측·불확실은 "확인 필요"로 명시**(사실인 척 금지). 1차 출처 우선. — 유저 최우선 가치.
- **컨텍스트 관리**: 🔑 훅이 target별 실측 임계로 **준비 → 인계**를 2단 안내한다. 준비에서는 `state/`를 갱신하고, 실제 인계 수단은 target의 session capability를 따른다. 그 주입이 없으면 **먼저 권하지 않는다** — *"길게 느껴진다"*는 근거가 아니다(cry-wolf). 유저가 수치를 언급하거나 auto-compact가 나면 그때는 응한다.
- **도식 렌더**: 유저는 **원격 터미널**이라 mermaid 텍스트가 그림으로 안 뜬다 → **확대 가능한 형태({{VIZ}})** 로 낸다. **적응적**(흐름·구조·결정 등 그림이 이해를 도울 때, 도식범벅 금지). 민감 도식은 {{VIZ}} 금지(= 반출) → 로컬 렌더.

## 🔑 문서 — 기록은 남기고, 산출물은 요청 있을 때만

| | |
|---|---|
| **기록** (`state` · `exec` · `decisions`) | **반드시 남긴다.** 규율이 아니라 **훅이 강제한다**(L3) — 파일을 고쳤는데 `state/`를 갱신하지 않으면 `Stop` 훅이 `exit 2`로 **응답을 못 끝내게 한다**. 2회까지 막고, 그래도 못 쓰면 훅이 최소 기록을 남기고 통과시킨다(교착 방지) |
| **산출물** (README · docs · docstring · 보고서) | **요청 있을 때만.** 스스로 만들어내지 않는다. 구현 중 관례상 최소 docstring은 코드의 일부로 허용하되 과하게 X |

같은 규칙의 양면이다 — **안 남기면 막고, 안 시켰으면 안 만든다.**

작업 기록은 `_local-docs`(= `~/projects/_docs/<project>/`)에 남긴다. 스키마 = `LOCAL-DOCS-SCHEMA.md`.
산출물 네 갈래(기록에 녹음 / repo 커밋 / 외부 / `out/<slug>/`)도 거기 정의돼 있다.
