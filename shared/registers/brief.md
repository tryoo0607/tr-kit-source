**표·결론 중심으로 낸다.** 근거는 요청받으면 편다.

백본을 타는 턴이면 맨 위에 이 블록:

```
────────────────────────────────────────
🔨 「수행」 · 고치기
   확신없음  install.sh --inno 가 회사 config 도 건드리는지
────────────────────────────────────────
```

대개는 안쪽이 **한 줄뿐이다.** 그래도 선은 긋는다:

```
────────────────────────────────────────
🔍 「점검」 · 알아내기
────────────────────────────────────────
```

- 아이콘: 🚪진입 · 📋정의 · 🗺️계획 · 🔨수행 · 🔍점검 · 📦마무리
- `가정`·`확신없음`은 **있을 때만**. 없으면 단계 줄 하나짜리 블록.
- 🔑 **수평선은 위아래 둘 다 항상 긋는다** — 구분자가 뜻이라 빼면 신호가 죽는다. 한쪽만은 더 나쁘다.
- 휘발성 턴(단순 조회·잡담)이면 전부 생략한다.

## ⛔ 스테이지 6종뿐 · 연속 턴도 매 턴 찍는다

- `완료`·`확인` 같은 라벨을 **지어내지 않는다.** 끝났으면 📦**「마무리」**, 하위 단계면 스테이지 유지 + 결과는 본문 첫 줄.
- 작은 턴이 20개 이어져도 **매번 블록을 낸다** — 제목이 아니라 **상태줄**이라서다. 같은 스테이지면 `· 루프 N`.

## 짧게 쓰는 규칙

- **결론부터.** 과정은 물으면 편다.
- 나열이 3개를 넘으면 **표로.**
- 코드·명령은 그대로, **설명은 한 줄.**
- 이미 합의된 것을 다시 설명하지 않는다.

⚠️ **짧음이 목표가 아니라 이해가 목표다.** 줄여서 뜻이 흐려지면 그건 brief 가 아니라 손실이다.
표 한 줄로 안 되는 판단은 문장으로 쓴다.

## 📋 완료 요약 — 결과는 밴드로 (brief 에선 특히)

실질 작업·조사가 **끝나는 턴**엔 벽처럼 쏟지 말고 요약 밴드로:

```
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 📋 요약 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓

<핵심 결과 — 표·도식 OK. 너무 짧으면 안 된다>

▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓

▸ [ 더 알면 좋은 것 ]
- 부가 정보 (표·중첩·소제목 — 형식·깊이 자유)
```

- 요약=알아야 할 것 / 더 알면=부가. `▓▓▓ 📋 요약 ▓▓▓` 열고 `▓▓▓▓▓` 닫음(요약만 감쌈). `▓`라 `═`(알림)과 갈림. 표 넣으면 **닫는 선 앞 빈 줄**.
- 표식 `▸ [ ... ]`, 그 안은 형식·깊이 자유. `─`·`----` 는 단계 신호라 구분선으론 안 쓴다.
- ⛔ **완료 턴에만.** 휘발성·중간 진행엔 안 낸다.

## 알림은 `═` 블록으로 — **brief 에서도 유지한다**

훅이 낸 알림(⚠️·⛔·🔧)은 평문으로 흘리지 말고 맨 위에:

```
════════════════════════════════════════
⚠️  컨텍스트 96% — 롤오버할 때다
    state/ 정리 후 /clear
════════════════════════════════════════
```

`─` 는 *지금 어디냐*, `═` 는 **네가 개입해야 한다**. 둘 다 나오면 알림이 위다.
둘째 줄엔 **유저가 할 일**을 쓴다. 알림 없는 턴에 `═` 를 지어내지 않는다.

## 첨언 `💭` — **brief 에서도 유지한다**

같은 `═` 블록에 `💭`. **다섯 종류뿐이고 대상이 구체적일 때만** 낸다.

| 연결 | 과거 케이스·결정과 같은 병 |
|---|---|
| **모순** | 기존 규칙·문서와 어긋남 |
| **파급** | 다른 머신·세션·프로젝트에 영향 |
| **비용** | 나중에 비싸짐 |
| **범위** | 요청 밖으로 번짐 |

⛔ 일반론 금지 · 근거 없이 반대 금지 · 본문에서 말한 걸 블록으로 또 내지 않는다.

## 미검증 누적

*"확인 필요"* 라 해놓고 **떠 있는 것**이 3건을 넘으면 `═` 블록으로 알린다.
기록(`state/`·`exec/`)에 남긴 건 센 것에서 뺀다.
