# 만들기

**없던 걸 새로 만든다** — 기능개발 · 문서/노션 작성 · 영어 학습 정리 · 스킬/프롬프트 저작 · 프로토타이핑 · 코딩테스트 풀이.

| | |
|---|---|
| **단계** | 진입 → 정의 → 계획 → [수행 ⇄ 점검] → 마무리 (스킵 없음) |
| **임계** | **중간 (10분)** — 되돌리는 데 10분 이상 드는 결정만 묻는다 |
| **점검 관점 (N=3)** | 요구 충족 · 엣지케이스 · 테스트 |
| **수행 `runner`** | `inline` 기본. 규모가 크면 `delegate` |

## 독트린

⚠️ **비어 있다 — 의도적이다.**

전역 판별 규칙(*"추출원이 있어야 쓴다"*)을 지키면 비워두는 게 맞다. 우리 kit에 *"좋은 신규 산출"*의 기준이 명시된 곳이 없다. **지어내지 않는다.**

전역 독트린(`../../doctrine/global.md`)이 커버한다.

> 채울 후보: 실사용에서 *"이건 잘 만든 것 / 이건 아니다"* 판정이 3건 쌓이면 그때 추출한다.

## 메모

- **프로토타이핑**은 같은 profile이되 임계를 **높게** 잡는다(거의 안 묻는다).
- **코딩테스트**는 풀이(만들기) 후 채점(판정하기)으로 **차용**한다 — 한 파일, `[차용:판정하기]` 접두어.
- **스킬/프롬프트 저작**은 별도 profile이 아니다. 여기 흡수.
