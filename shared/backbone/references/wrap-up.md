# 「마무리」 상세

## 완료 후처리 후보 — 한 일에 매핑해서 **관련만** 제시

| 후보 | 언제 뜨나 | 부르는 것 |
|---|---|---|
| commit / PR | 코드 변경 있음 | `git` (회사 repo면 사내 양식) |
| career-log | 성과·배움 있는 작업 | `career` |
| 문서화 | 프로젝트 내부 문서 갱신 필요 | `convention` — **요청 있을 때만** |
| 도메인 저장소 반영 | 별도 도메인 plugin이 소유하는 설정·구성 변경 | 설치된 도메인 skill |
| `_local-docs` 백업 | 기록이 바뀜 | `local-docs-backup`(bin) — cron(하루 1회)의 보강 |
| 세션 마무리 | 세션 끝·컨텍스트 정리 | `session` |
| secret 점검 | secret 다뤘음 | `secrets` |

- **실제 한 일과 무관한 후보는 숨긴다.** 매번 같은 체크리스트를 뿌리면 아무도 안 읽는다.
- **기본은 물어보기.** 자동 실행하지 않는다.

## 🔑 무엇을 memory에 남기고 무엇을 기록에 남기나

둘 다 남기는 곳이라 헷갈린다. **가르는 건 "다음 세션에 저절로 떠야 하나"**다.

| | memory | `_local-docs` |
|---|---|---|
| 성격 | **사실** — 짧고, 세션을 넘어 항상 참 | **경위** — 무엇을 왜 어떻게 했나 |
| 로드 | **매 세션 자동** | 필요할 때 읽는다 |
| 예 | *"tmux 서버는 공유다 — kill-server 금지"* | 이번 작업의 결정·시행착오·검증 |
| 크기 | 한 줄~몇 줄 | 제한 없음 |

**판별:** *"다음 세션이 이걸 모르면 사고가 나나?"* → 예면 memory. *"나중에 왜 그랬는지 궁금할 것 같다"* → 기록.

- 🔑 **양쪽에 같은 걸 쓰지 않는다** — memory에 경위를 쓰면 매 세션 비용을 내고, 기록에만 사실을 두면 다음 세션이 모른다.
- **프로젝트가 아니면 memory만** 있으면 된다.
- memory는 **쓴 시점의 사실**이다. 파일·플래그를 지목하는 memory는 **여전히 존재하는지 확인하고** 쓴다.

## 🔑 태그를 붙이면서 넛지도 같이 본다 (⑨ 자기확장)

`exec/<slug>.md`에 **분류 태그**를 붙일 때, 같은 태그가 **3건째**면 알린다.

```bash
grep -h '^| 태그 |' ~/projects/_docs/<project>/exec/*.md | tr '·' '\n' | sed 's/[| ]//g' | sort | uniq -c | sort -rn
```

- **`exec/`가 정본이다** — 별도 인덱스를 만들지 않는다. 손으로 유지하는 인덱스는 드리프트한다.
- **비용이 0이다** — 어차피 태그를 붙이는 중이니 세는 김에 본다.

> **3인 이유**: 2는 우연이고 10은 늦다 (Rule of Three).

🔑 **넛지는 알림이지 게이트가 아니다.**

```
"이 태그로 3건째다. 스킬로 만들까?"    → 무시해도 진행된다
```

무시했으면 **그 사실을 기록**해서 4건째에 또 묻지 않는다. 반응이 없는 알림을 반복하면 진짜 신호까지 묻힌다.

**구조가 안 맞는 건 자동 감지하지 않는다** — 「진입」에서 profile을 자꾸 묻게 되거나, 차용이 2단계 이상 필요해지면 그건 **사람이 말할 일**이다.

## 절차

1. 완료 신호 감지.
2. 한 일을 요약하고 **관련 후보만** 골라 조립.
3. 프로젝트 오버라이드가 있으면 병합.
4. 제안 → 확인 → 순차 실행.
5. **스킵한 것도 기록한다** — 안 한 게 아니라 미룬 것이면 그렇게 보여야 한다.

## 프로젝트별 오버라이드

`_local-docs`에 둔다(형식 = `LOCAL-DOCS-SCHEMA.md`). 담는 것:

- **단계 추가·수정** — 이 프로젝트 고유 단계(예: 배포 승인)
- **필수 후처리** — 완료 시 반드시 할 것
- **완료조건(DoD)** — 무엇을 충족해야 "완료"인가

**충돌하면 프로젝트가 이긴다** (더 구체적인 게 이긴다 — 스킬 선택과 같은 축).
