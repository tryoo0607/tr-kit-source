# Claude Code — native Artifact 연결

## 목적과 역할 경계

- artifact-publish가 선택한 Claude Code 게시 연결이다. 현재 세션의 native Artifact 도구만 사용하며 API·자체 서버·업로더를 구현하지 않는다.
- 내용·계정/공유 범위·전송 검사·완료 기준은 공통 skill이 소유한다.

## 입력과 전제

- 완성본·제목·기존 URL/현재 연결 artifact·본인 전용 범위와 현재 native 도구의 schema/가용성을 확인한다. 다른 세션 갱신도 기존 식별자가 필요하며 추측한 URL에 쓰지 않는다.
- 공식 문서는 기본 비공개와 동일 URL 갱신, 세션/계정·조직 조건을 설명한다. 이 설명은 현재 세션의 실제 지원·권한 증거가 아니다. [공식 Artifact 문서](https://code.claude.com/docs/en/artifacts)를 필요한 항목만 확인한다.

## 수행 방법과 절차

1. 실제 도구 schema로 요청한 새 게시/기존 갱신을 선택한다. 알려지지 않은 필드·API·endpoint를 추측하지 않는다. 도구가 없거나 계정/조직 조건을 충족하지 못하면 파일을 보존하고 게시를 보류한다.
2. 단일 페이지로 준비하고 현재 형식·크기·CSP 조건을 공식 문서와 실제 도구에 대조한다. 상대 파일/로컬 서버에 의존한 채 게시 성공을 주장하지 않는다. 표현을 조정해야 해도 원본 의미·관계를 유지하며 외부 라이브러리/자료 반출을 임의 추가하지 않는다.
3. 현재 동작이 source 파일 수정도 포함하는지 확인해 승인 범위를 대조한다. 요청하지 않은 정본 수정·connector/다운로드 capability 추가·공개 공유를 게시의 부수 작업으로 실행하지 않는다.
4. native 반환 URL·게시/갱신 결과와 권한 범위를 대조하고 지원되는 실제 렌더를 확인한다. CSP 때문에 비는 도표는 실패/미검증으로 보고하고 확인한 지원 표현으로만 보완한다.

## 연계와 의존

| 대상 | 전달 입력·필요 결과 | 필수 여부·부재 처리 |
| --- | --- | --- |
| 현재 Claude Code의 native Artifact 도구 | 단일 페이지·제목·기존 식별자·계정/공유 범위. 결과는 실제 URL·게시/갱신 상태·접근/렌더 근거 | 필수. 실제 schema·접근 부재/거부는 보류. Sites·nginx·별도 credential로 자동 대체하지 않음 |

## 결과와 완료 판단

- 파일 준비·게시·계정 보호·로그인 화면 렌더를 각각 보고한다. 인증 안내·예상 URL·로컬 HTML을 게시 완료로 표시하지 않는다. 이 reference가 존재한다는 사실을 native 지원이나 실행 검증으로 확대하지 않는다.
