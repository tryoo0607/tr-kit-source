# Claude Code의 아티팩트 게시

Claude Code에서 계정 전용 결과 페이지를 만들거나 갱신할 때 사용한다. 별도 서버 대신 현재 세션의 native Artifact 도구를 재사용한다.

## 수행 방법과 절차

아래 native Artifact 연결 계약을 적용한다. 기존 페이지는 지정한 URL의 최신 버전에 반영한다. 필드 이름은 실행 중 도구 schema를 따르며 API를 복제하지 않는다.

다른 세션의 페이지 갱신에는 해당 URL 또는 현재 세션에 연결된 artifact가 필요하다.

페이지는 독립된 단일 파일로 준비하고 같은 페이지의 섹션은 anchor로 연결한다. 상대 파일, 로컬 서버 및 허용되지 않은 외부 리소스에 의존하지 않는다. CSP로 인터랙션이나 도표가 비면 원본 관계를 보존해 지원되는 HTML/SVG 표현으로 조정하고 실제 렌더를 재확인한다. 현재 페이지 크기와 형식 제약은 필요할 때 [공식 문서](https://code.claude.com/docs/en/artifacts#page-constraints)로 확인한다.

임의 API나 브라우저 세션 credential로 게시하지 않는다.

## 연계와 의존

| 대상과 요청 | 입력 | 필요한 결과 | 의존과 부재 시 동작 |
|---|---|---|---|
| Claude Code native Artifact: 새 페이지 게시 또는 기존 URL 갱신 | 완성한 단일 파일, 제목, 기존 URL, 본인 전용 접근 | 도구가 반환한 실제 URL과 게시 결과, 접근 및 렌더 확인 | 필수. 현재 도구 schema로 실행하며 부재와 로그인/조직 거부는 보류하고 알림 |

## 결과와 완료 판단

publish 성공과 반환 URL을 확인한다. 계정 보호 확인과 로그인한 사용자가 페이지를 실제 열어본 결과를 구분한다. 도구 호출 전의 로컬 HTML 경로나 예상 URL을 게시 완료 링크로 전달하지 않는다.
