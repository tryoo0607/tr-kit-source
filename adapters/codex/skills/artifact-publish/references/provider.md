# Codex의 Sites 게시

Codex에서 계정 전용 페이지를 만들거나 갱신할 때 사용한다. 플랫폼의 실제 도구와 공식 Sites skill을 재사용한다.

## 수행 방법과 절차

아래 Sites 연결 계약으로 해당 SKILL.md에 진입한다. 새 사이트는 독립된 작업 폴더에 필요한 파일만 준비하고 기존 사이트는 확인된 project_id를 유지한다.

정적 HTML은 공식 Sites의 buildless static 경로를 사용한다. 이 reference에 등록, Git 인증, 버전 저장과 배포 명령을 복제하지 않는다. 해당 skill의 조립 및 게시 절차와 기본 비공개 범위를 따른다. 사이트 생성은 게시 완료가 아니며 배포 상태와 접근 설정을 확인한다.

credential을 복사하거나 별도 업로더를 설치하지 않는다. 비용 질문에는 현재 공식 Sites 요금과 포함량을 확인하고 영구 무료를 약속하지 않는다.

## 연계와 의존

| 대상과 요청 | 입력 | 필요한 결과 | 의존과 부재 시 동작 |
|---|---|---|---|
| Sites plugin의 sites skill: 정적 결과물 게시 또는 갱신 | 필요한 파일만 포함한 작업 폴더, 제목, 기존 project_id/URL, 승인된 접근 범위 | 게시 URL, 배포 완료 상태, 소유권과 접근 범위, 확인 한계 | 필수. 현재 도구 및 SKILL.md가 없거나 거부되면 파일만 보존하고 게시 보류 |

## 결과와 완료 판단

기존 사이트의 audience가 요청과 다르면 공개 범위를 바꾸지 말고 충돌을 보고한다. 계정 인증이 필요한 URL은 사용자 브라우저 확인과 비로그인 접근 차단을 구분해 기록한다.
