# prototype

아이디어·화면을 **버려도 되는 단일 HTML 목업**으로 빠르게 확인한다. 방향·레이아웃·흐름을 보는 용도이며 프로덕션 코드가 아니다.

## 공통 규율

- 인라인 CSS/JS를 사용한 단일 자체완결 HTML로 만든다.
- 실제 API 대신 의미 있는 목데이터를 채우고 데이터 연결 전임을 밝힌다.
- 여러 화면은 한 파일의 섹션·탭으로 전환한다.
- 반응형과 light/dark를 고려하고 외부 의존은 최소화한다.
- 워치·모바일 프레임이 필요하면 `references/frames.md`를 읽는다.
- 저충실도 스케치에서는 장식보다 정보 구조와 이동 흐름을 우선한다.
