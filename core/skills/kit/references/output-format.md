# 산출물 형식 — 설계 가이드 · 검토 체크리스트

스킬이나 반복 산출물(요청서·리포트·`index.json`·큐)이 **내놓는 출력의 모양**을 정한다.
**설계**(새로 만든다)와 **검토**(기존 양식을 감사한다) 두 모드로 쓴다 — 아래 **4번이 검토용 체크리스트**다.

## 1. 형식 종류 결정 (상세)

| 형식 | 강점 | 쓸 때 | 주의 |
|---|---|---|---|
| **마크다운(표 중심)** | 사람이 바로 읽음·스캔 | 문서·핸드오프·리포트 | 기계 파싱엔 부적합 |
| **JSON (스키마)** | 앱·스크립트 파싱 | 다른 skill/앱이 소비 | 사람이 읽기 불편 → 예시 필수 |
| **frontmatter + 본문** | 메타(질의) + 서술(사람) | 레코드형 문서(레벨·srs·태그) | YAML 중첩 회피 = **평면 키**(예 `srs_box`) |
| **JSONL** | append-only·스트림·부분소비 | 이벤트 로그·항목 축적 | 한 줄=한 레코드, 스키마 고정 |

**결정 축 = 누가 먹나:**
```
사람만 → 마크다운(표)
기계만 → JSON / JSONL
둘 다 → frontmatter(레코드)  또는  md(사람)+파생 json(기계) 이중 산출
```

## 2. 구조 규약 (설계 원칙)

### 표 우선
다항목·대비 데이터는 표. 열 = 고정 필드. 자유서술은 표 밖 상세 절로.

### 깊이 단계 (verbosity scaling)
출력이 요청에 따라 커져야 하면 **모드**로 분리하고, "어느 섹션이 어느 모드에 드는지" **매핑 표**를 둔다.
```
| 섹션 | 간단 | 상세 | 최대 |
|---|---|---|---|
```
기본 모드 명시(안 물으면 무엇). 예 = `api-handoff`(간단/상세/패치).

### 필드 가이드
각 필드: **의미 + 채움 지침 + 예시값**. 특히:
- 모르는 값 = **"확인 필요"** 표기. 추정으로 채우지 않는다(근거 규율, hot 규칙).
- 파생 가능 값(diff·소스에서)은 도출법 힌트.

### taxonomy / enum
고정 분류는 **닫힌 목록**으로 정의(추가/변경/삭제 등). 각 값의 의미·시사 표로.

### 예시
**채워진 실제 예시** 하나 이상. 빈 틀 + 예시 둘 다.

## 3. 소비 계약 (machine-consumed)
- **안정 키**: 한번 정한 키명 유지. 바꾸면 소비자 깨짐.
- **스키마 정본 1곳**: repo README나 스키마 파일. 스킬 본문은 참조만(DRY, 중복 정의 금지).
- **진화**: 필드 추가는 하위호환(옵셔널), 제거·개명은 버전/마이그레이션 노트.
- **out/in 분리**: 생성물(out)과 입력(in)을 다른 파일로. 예 = 워치 계약 `review-queue.json`(out) / `answers.jsonl`(in).

## 4. 검토 모드 체크리스트 (기존 양식 감사)
- [ ] 형식 종류가 **소비자**에 맞나? (사람인데 JSON, 기계인데 표 아님?)
- [ ] 다항목인데 **표** 안 쓰고 산문인가?
- [ ] 분량이 요청 따라 커지는데 **깊이 모드** 없나? (항상 최대치만 뱉나?)
- [ ] 각 필드 **의미·채움 지침**이 있나? 모르는 값 "확인 필요" 규율 있나?
- [ ] 고정 분류가 **enum**으로 닫혔나, 자유서술로 샜나?
- [ ] **채워진 예시**가 있나?
- [ ] 기계 소비면 **안정 키·스키마 정본**이 한 곳에 있나? 중복 정의 없나?
- [ ] 기존 kit 패턴 **재사용**했나, 새로 발명했나? (표스타일·깊이·append-only·계약)

## 5. kit 내 레퍼런스 (모범례)
| 산출물 | 형식 | 배울 점 |
|---|---|---|
| `api-handoff` `template.md` | md·표·깊이3 | 표 우선 + 깊이 모드 + 필드 가이드 |
| 검색 index | JSON | 앱 소비용 파생 산출 |
| review queue/event log | JSON/JSONL | out/in 계약 분리 |
| 분류별 note | frontmatter Markdown | 평면 키로 YAML 중첩 회피 |
| `history.jsonl` | JSONL | append-only 이벤트 축적 |
