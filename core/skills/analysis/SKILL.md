# analysis

프로젝트/코드베이스 구조를 **온보딩용 자체완결 HTML**로 낸다. 여러 프로젝트가 한 시리즈로 읽히도록 골격·헤더·도식·각주 규격을 공유한다.

## 시작

`references/skeleton.html`을 바탕으로 작성하고, 상세 규격은 `references/spec.md`, SVG 패턴은 `references/svg-patterns.md`를 필요한 부분만 읽는다.

## 공통 골격

```text
01 개요 → 02 용어·약어 → 03 컴포넌트 구조 → 04 데이터흐름 → 프로젝트 고유 → 읽기 진입점
```

- 제목은 `[<프로젝트>] 구조 분석`으로 한다.
- 사이드바로 뷰를 전환하고 URL hash로 현재 뷰를 유지한다.
- metabar에 기준·근거·범위와 `근거·확신 없는 것`을 둔다.
- 컴포넌트 목록, 계층도, 모듈 배선도, 데이터 흐름을 서로 다른 질문으로 구분한다.
- 검증 가능한 주장에는 출처를 달고 추정은 `확인 필요`로 표시한다.
