# homelab-record

## 목적과 역할 경계

홈랩 운영 사실과 근거의 의미를 관리한다. 기록 위치와 기존 작업 정본 연결은 document를 재사용하고 실제 상태 비교는 homelab-audit에 맡긴다. 독립 호출 시에도 같은 경계를 지킨다.

## 입력과 전제

대상, 변경 이유와 확정 범위, source revision, 실행 결과 및 관측 근거, 기존 작업 포인터를 받는다. 연결이 불명확할 때만 [저장소 연결](../homelab/references/repository.md)을 읽는다. 매 편집마다 확정을 묻지 않는다.

## 수행 방법과 절차

1. 기존 작업 정본과 관련 운영 이력을 먼저 읽어 이미 기록된 건, 취소된 건과 아직 미확인인 건을 구분한다. 동일 작업/실행 ID의 중복 기록과 중복 질문을 피한다. 기존 기록을 읽지 못하면 '미기록'으로 단정하지 않는다.
2. 의도 확정, source 저장, 실제 반영 관측, 검증 결과, 기록 여부를 각각 확인한다. source 커밋만 있거나 실행 성공 메시지만 있으면 실제 적용/검증 완료로 올리지 않는다.
3. 미확인이면 근거에 따라 실제 상태 조회가 필요한지와 기록 여부만 확인하면 되는지를 나눈다. 조회가 필요하면 아래 연결을 적용한다. 사용자에게는 대상과 남은 불확실성을 짚어 묻고 기존 승인을 다시 요청하지 않는다. 예를 들어 "이 설정은 실제 반영됐는지, 확인한 결과를 기록할지"를 묻되 이미 받은 답과 관측을 재사용한다. 의도 확정이나 기록만 필요한 경우 재적용하지 않는다.
4. 확정 운영 변경에는 이유, 대상, source revision 또는 미커밋 여부, 실행 경로와 작업 ID, 검증 결과 또는 명시적 미확인, 관측 시각과 롤백 참조를 남긴다. 조회 결과가 있어도 의도 변경인지 불명확하면 자동으로 source를 채택하지 않는다.
5. 실패/중단/미확인도 기존 작업 정본에 근거와 다음 확인을 보존한다. 확정 운영 이력과 작업 진행 상태를 복제하지 않고 링크로 연결한다. 새 pending 파일, DB나 보드를 기본 생성하지 않는다.
6. 구조가 바뀌었으면 아키텍처 정본 갱신 필요와 대상 관계를 기존 작업 정본에 연결한다. 관계 정본 갱신은 homelab-architecture의 책임이다. 이미 받은 갱신 결과는 연결하고, 결과가 없으면 갱신 미확인으로 남긴다. 여기서 관계 편집이나 작도를 대신 수행하거나 해당 스킬을 다시 호출하지 않는다. 공유 파일의 통합 규칙을 지키고 갱신이 이월되면 미결로 남긴다.
7. 기록을 다시 읽어 저장 위치와 사실/미확인의 구분을 확인한다. 다음 홈랩 작업 또는 명시 재조회에서 미확인 항목을 다시 확인한다. 거절/취소는 다시 묻지 않으며 실제 해결 또는 명시 처분 근거가 있어야 미확인을 닫는다.

## 연계와 의존

| 대상 | 활용 조건과 입력 | 결과와 부재 시 동작 |
|---|---|---|
| [document](../document/SKILL.md) | 기록 조회/갱신 시 기존 작업 정본, 저장 범위와 홈랩 운영 사실 전달 | 실제 기록 위치와 저장 확인. 해당 요청에 필수, 없으면 기록 쓰기 보류 |
| [homelab-audit](../homelab-audit/SKILL.md) | 실제 적용 근거가 부족할 때 대상, source와 필요한 관측 전달 | 항목별 관측 근거와 미확인. 조회가 불가하면 사유를 기록하고 적용 여부는 미확인 유지 |

각 대상 SKILL.md의 해당 분기와 공통 제약을 적용한다. 이미 충분한 관측이나 저장 확인을 받았으면 같은 도구를 재실행하지 않는다.

## 제약과 주의점

기존 호스트 가드, 기록 정책과 사용자 승인 범위를 지킨다. 개인 주소/상세 topology는 private 자료 범위에만 보관하고 비밀값 원문을 로그에 넣지 않는다. 기록 저장은 commit, push 또는 동기화 실행 승인이 아니다. 세션 밖 재질문이나 미확인 항목 자동 탐지를 보장하지 않는다.

## 결과와 완료 판단

조회 결과 또는 실제 저장 위치, 확정 사실과 미확인, 아직 필요한 질문과 다음 확인 조건을 전달한다. 문서를 작성했다는 이유로 실제 변경이나 전체 작업을 완료 처리하지 않는다.
