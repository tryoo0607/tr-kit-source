# ext-github-readme-generator

## 목적과 역할 경계

- 요청한 README의 명령·제품 지원·설정·주장을 실제 구현과 대조하고 공식 작성/감사 절차로 연결한다. 다른 업무 문서를 여기서 관리하지 않는다.
- 감사는 수정 승인이 아니다. README에 맞추려고 코드·시험·설정·의존성을 바꾸지 않는다.

## 입력과 전제

- 실제 저장소/checkout, 기존 README 또는 지정 파일, 요청 모드·언어·독자·유지할 설명과 변경 범위를 받는다. 확인하지 않은 실행 상태·라이선스·지원·배지를 만들지 않는다.

## 수행 방법과 절차

1. 아래 공통 연결로 공식 SKILL.md에 진입해 실제 모드의 원문 절차를 적용한다. 공식 reference는 해당 설치 root 기준으로 읽는다.
2. 공개할 명령은 entrypoint에서 실제 호출 함수와 제품 설정까지 확인해 필수 인자·옵션·사전조건·변경 효과를 대조한다. 기존 README/CI에 같은 문장이 있다는 사실만으로 유효하다고 판정하지 않는다.
3. 명령·제품 차이·근거 충돌이 있을 때 해당 범위를 깊게 확인하고 허용된 임시 실행만 수행한다. 문서 검토를 설치·fetch/push·실서버 실행 승인으로 확대하지 않는다. 단순 문구 수정에 전수 실행·별도 agent를 강제하지 않는다.
4. 작성·압축·재배치 후 최종 명령과 핵심 역할·제품 범위를 다시 대조한다. 근거는 기존 검토 메모/출처에 연결하고 명령 정본을 따로 복제하지 않는다. 수정 제안 명령도 같은 기준을 적용한다.

## 연계와 의존

| 대상 | 전달 입력·필요 결과 | 필수 여부·부재 처리 |
| --- | --- | --- |
| 외부 연결 `github-readme-generator` · 종류 skill. [공통 외부 연결](../../references/external-connection.md) | 실제 repo·요청 모드/파일·기존 근거·보존 요구·범위. 결과는 README/감사 발견·claim 근거·검사/미검증 | 공식 수행에 필수. 부재 시 관련 수행 보류. 자체 원문 사본·동명 외부 연결로 대체하지 않음 |

## 결과와 완료 판단

- 작성/수정/감사 결과와 실제 조사한 구현·검증·남은 미확인을 구분한다. 형식·링크·호출 조건 확인과 실제 실행은 다른 증거다. 실행하지 않은 명령을 동작 검증 완료로 보고하지 않는다.
