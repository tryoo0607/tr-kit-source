# homelab

## 목적과 역할 경계

개인 홈랩 작업의 진입점이다. 설정 변경은 homelab-config, 구성 관계는 homelab-architecture, 복구 준비와 검증은 homelab-recovery, 실제 비교는 homelab-audit, 운영 사실 기록은 homelab-record가 맡는다. 각 기능은 단독 사용 가능하며 이 스킬의 선행 실행을 요구하지 않는다. 작업 계획과 상태는 BMAD 또는 기존 작업 정본을 재사용한다.

## 입력과 전제

대상, 요청 범위와 기존 연결을 확인하고 [저장소 연결](references/repository.md)을 적용한다. 개인 주소, repo URL과 인증값을 public 지침에 복제하지 않는다. 운영 조회와 변경 전에는 현재 호스트 가드를 적용한다.

## 수행 방법과 절차

1. 관련 작업 정본에서 미확인 후속만 읽는다. 이미 취소하거나 거절한 항목은 다시 묻지 않는다. 읽을 수 없으면 미확인 항목이 없다고 단정하지 않는다.
2. 아래 연결 계약에서 요청에 필요한 기능만 적용한다. 이미 받은 연결과 검증 근거는 재사용한다. 설정 변경에 관계 갱신도 포함되면 config의 결과를 architecture에 전달한다. source만 저장한 계획을 현재 운영 관계로 올리지 않는다.
3. 의도 확정, source 저장, 실제 반영 관측, 검증 결과와 기록 여부를 구분해 종합한다. 다음 확인 대상과 불가능했던 검증을 남긴다.
4. 복구 요청은 준비 점검, 백업 검사, 격리 시험과 실제 복구를 구분해 recovery에 전달한다. 계획이나 source 저장을 복호화, 서비스 중단과 복원 실행 승인으로 확대하지 않는다.

## 연계와 의존

| 대상 | 활용 조건과 입력 | 결과와 부재 시 동작 |
|---|---|---|
| [homelab-config](../homelab-config/SKILL.md) | 설정 변경 계획, source 저장, 실제 반영 또는 수동 변경 사후 정리. 대상, 원하는 값, 작업 포인터, 실행 소유자, 승인 범위와 기존 관측 전달 | 저장과 반영의 구별, 검증과 기록 결과 및 미결. 해당 요청에 필수이며 없으면 관련 변경을 보류한다. 비교와 기록 절차는 config에 맡기고 중복 실행하지 않는다. |
| [homelab-architecture](../homelab-architecture/SKILL.md) | 구성 관계 점검이나 갱신, 의존성 정리와 관련 작도. 대상, 관계 정본, 작업 포인터, 변경 근거와 확인 범위 전달 | 관계 근거와 델타, 정본 갱신 및 작도 결과와 미확인. 해당 요청에 필수이며 없으면 관계 갱신을 보류한다. 실제 조회와 기록 결과는 재사용한다. |
| [homelab-recovery](../homelab-recovery/SKILL.md) | 백업 검사와 복구 준비, 격리 시험 및 실제 복구. 대상과 장애 가정, 기존 런북, 후보 백업, 실행점과 승인 범위 및 기존 근거 전달 | 검사와 복원 및 의미 검증 범위, 독립성 근거와 미확인. 해당 요청에 필수이며 없으면 복구 실행을 보류한다. 기존 결과를 재사용하고 같은 관측이나 기록을 중복 실행하지 않는다. |
| [homelab-audit](../homelab-audit/SKILL.md) | 실제 상태나 적용 여부 확인. 대상, repo 연결, 설정 소유자, 의도 source와 관측 범위 전달 | 일치, 불일치, 미확인과 근거. 해당 요청에 필수이며 없으면 비교 실행 보류 |
| [homelab-record](../homelab-record/SKILL.md) | 변경 기록이나 미확인 후속 조회. 대상, 기존 작업 포인터, 확정 범위와 검증 결과 전달 | 저장 위치와 기록 상태, 미확인 질문. 해당 요청에 필수이며 없으면 기록 실행 보류 |

대상의 SKILL.md에서 해당 절차와 공통 제약을 읽고 적용한다. 연결 표는 별도 프로세스나 자동 호출 장치가 아니다.

## 결과와 완료 판단

확인한 대상과 사용한 기능, 실제 관측 범위, 기록 위치, 남은 미확인을 전달한다. 지침 작성, source 저장 또는 과거 기록 조회를 실제 적용 성공으로 보고하지 않는다. 세션 밖 자동 감지나 알림을 보장하지 않는다.
