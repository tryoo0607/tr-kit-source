# ext-mem-search

## 목적과 역할 경계

- 이전 경험 후보·맥락·선택 상세를 찾아 근거와 적용 범위를 반환한다. 오래된 시도와 성공·현재 요구를 구분한다.
- 현재 작업 상태는 기존 BMAD/작업 정본에서 확인한다. 경험 검색을 기억 저장·Wiki 반영·worker 시작으로 확대하지 않는다.

## 입력과 전제

- 질문·project/server 범위·기간·기존 ID를 재사용한다. 사용자가 제공한 자료만으로 충분하면 전체 DB 검색을 추가하지 않는다.
- 현재 세션에서 공식 MCP 서버와 실제 tool/schema가 있어야 한다. 제품/배포별 식별자·ID 자료형 차이를 추정해 호출하지 않는다.

## 수행 방법과 절차

1. 아래 공통 연결로 공식 mem-search SKILL.md에 진입한다. 공식 검색 순서·필터·상세 선택·실제 API schema를 적용한다. kit의 원문 사본이나 자체 DB launcher를 사용하지 않는다.
2. 후보에서 질문에 맞는 것만 상세 조회하고 원문·관측 시점·당시 결과·현재 적용 가능성을 구분한다. 검색 hit를 검증된 현재 사실로 보고하지 않는다.
3. 도구 오류/연결 부재와 0건을 구분한다. 불가하면 가능한 제공 자료만 검토하고 조회 한계를 남긴다.

## 연계와 의존

| 대상 | 전달 입력·필요 결과 | 필수 여부·부재 처리 |
| --- | --- | --- |
| 외부 연결 `mem-search` · 종류 skill. [공통 외부 연결](../../references/external-connection.md) | 질문·서버/project·기간·선택 ID. 결과는 후보/상세·원문 포인터·시점·한계 | 실제 기억 검색에 필수. 공식 entry 또는 native MCP 부재 시 검색 미실행, 자동 설치/worker 실행/전체 export 금지 |
| [document](../document/SKILL.md) | 작업 정본 비교나 명시적 기록 갱신이 추가로 필요할 때 기존 포인터·확인 결과 | 조건부. 단순 경험 검색에 기본 연속 적용하지 않음 |
| [Claude-Mem 실행기 연결](../../references/claude-mem.md) | 사용자가 별도로 요청한 MCP 준비·진단 또는 worker 수명 관리 | 조건부. 검색 실패에 자동 적용하지 않으며 설치·시작·수집과 실제 검색의 승인은 구분 |

## 결과와 완료 판단

- 실제 검색 범위·선택 관측·당시 상태와 현재 요구 차이·미확인을 보고한다. 저장·기록 갱신·작업 완료를 주장하지 않는다.
