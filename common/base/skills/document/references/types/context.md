# 맥락 안내와 세션 분석

프로젝트 자료를 찾는 안내나 이 대화에 한정된 분석을 조회, 작성, 갱신할 때 읽는다. 재사용 지식은 knowledge, 작업 재개는 handoff 분기가 소유한다.

## 입력과 전제

대상 프로젝트나 작업, 기존 안내와 분석 위치를 확인한다. 기존 명세, BMAD 맥락 자료나 Wiki가 충분하면 재사용하고 별도 index나 metadata를 요구하지 않는다.

## 수행 방법과 절차

1. 첫 질문이나 행동에 관련된 자료와 필요한 절을 찾는다. 부족하면 도구 연결의 작업/지식/경험 조회를 선택한다. 과거 인계를 연쇄 조회하지 않는다.
2. 프로젝트 공통 설명과 이 대화의 비교, 가설, 미확인 분석을 구분한다. 현재 코드에 관한 주장은 실제 checkout과 대조한다.
3. 작성 요청이면 허용된 기존 위치와 형식에 필요한 안내나 분석만 반영한다. 안내는 상세 정본과 읽을 조건을 연결하고 지식 본문을 복제하지 않는다. 세션 분석을 프로젝트 공통 결정으로 자동 적용하지 않는다.
4. 재사용 지식으로 남기는 요청이 추가되면 knowledge 분기를 적용한다. 작업 진행 상태나 승인 정본을 안내 문서로 대체하지 않는다.

## 결과와 완료 판단

자료 위치와 적용 범위, 실제 대조한 근거와 미확인을 구분한다. 작성했으면 링크와 내용 반영을 확인하고 조회만 했다면 파일을 만들지 않는다.
