# 지식과 작업 근거 연결

공부 메모, 조사 자료, 작업 경험을 저장하거나 지식으로 정리, 조회, 갱신할 때 읽는다. 완성된 결론이나 개발 작업의 결과만 대상으로 제한하지 않는다. 학습 대화, 퀴즈와 학습 일정은 담당하지 않는다.

## 입력과 전제

주제, 자료나 관련 작업, 요청이 단순 저장인지 지식 정리인지 확인한다. 개인 공부 지식과 프로젝트 고유 결정, 이 대화에만 유효한 분석을 구분한다. 프로젝트에서 배운 일반 개념이라도 내부 코드나 결정을 개인 지식 공간에 자동 복사하지 않는다.

## 수행 방법과 절차

1. 도구 연결의 Wiki 조회로 관련 주제와 기존 출처를 찾는다. 작업에서 나온 지식이면 작업 기록과 필요한 경험만 함께 조회한다. 이미 충분한 근거를 받았다면 다시 검색하지 않는다.
2. 재사용할 내용과 일회성 진행 상태를 구분한다. 사실, 사용자 의견, 해석, 미확인 질문과 근거의 시점/버전/적용 범위를 보존한다. 새 근거가 없는데 오래됐다는 이유만으로 기존 결론을 폐기하지 않는다.
3. 저장은 자료 수집, 정리는 기존 지식과 대조한 합성, 조회는 근거 기반 답변으로 구분해 Wiki 연결에 전달한다. 자료 수집만 끝났다면 지식 통합까지 완료했다고 하지 않는다. 정정은 원래 근거를 지우는 대신 기존 설명과 정정 자료의 관계를 남긴다.
4. 의미 있는 충돌은 범위와 근거를 대조한다. 해결되지 않으면 미확인으로 남기고, 사용자 결정이나 적용 범위를 바꿔야 할 때만 판단을 받는다. 기억의 관측을 검증된 지식으로 자동 승격하지 않는다.
5. 같은 자료를 다시 처리할 때 기존 출처와 반영 위치를 재사용한다. 저장된 내용과 링크를 확인하고 필요한 작업 정본에 지식 위치를 연결한다. 지식 변경이 현재 작업의 요구를 바꾸는지는 별도로 판단한다.

저장소 대체 요청은 기존 자료 처리, 실제 이관, 소비자 연결 변경, 사용 종료, 보관과 삭제를 구분한다. 최신 사용자 원문과 승인 범위를 확인하며 새 저장소를 만들었다는 사실이나 비어 있는 Wiki를 이관 근거로 삼지 않는다. 이관한 원본과 목적지, 누락 여부와 필요한 내용 검증을 대조하고 경로 설정 및 검색 소비자가 여전히 이전 정본을 사용하는지 확인한다. 미정인 기존 자료 처리를 계속 사용하거나 영구 보관하는 합의로 바꾸지 않는다. deprecated 표시, GitHub archive와 제거를 서로 대신 실행하지 않는다. 이관이나 제거 조건을 확인하지 못하면 미확인으로 남기고 전체 교체 완료로 보고하지 않는다.

## 분량과 읽기 범위

관련 주제와 후보 목록에서 시작해 답변이나 변경에 필요한 근거만 읽는다. 전체 DB, Wiki와 작업 이력을 한 번에 내보내거나 원문 전부를 작업 계획에 붙이지 않는다.

## 결과와 완료 판단

자료 위치, 반영한 지식과 출처, 확인 범위와 미결을 전달한다. 저장, 지식 합성, 사실 검증을 구별한다. 반복 사본과 상충하는 정본을 만들지 않았는지 확인한다.
