# 재개에 필요한 기존 기록 확인

기존 작업 기록의 위치와 누락된 결과를 확인한다. 인계를 위한 별도 상태·요약 정본을 만들지 않으며 실제 원문 조회와 세션 전달은 session이 맡는다.

## 수행 방법과 절차

1. 요청과 기존 작업 포인터를 확인한다. BMAD 작업은 도구 연결의 BMAD 절차로 계획·티켓·진행 기록을 조회한다. 비BMAD 기록은 현재 위치와 형식을 유지한다.
2. 현재 요구·미완료·검증과 다음 행동이 충분하면 기존 포인터를 반환한다. 최신 정정이나 수행 결과가 빠졌을 때만 담당 기록 기능으로 반영하고 다시 확인한다. 조회나 인계 요청만으로 build·계획 재작성·새 HANDOFF.md 생성을 시작하지 않는다.
3. 현재 checkout·revision·미커밋 범위와 기록의 차이를 밝힌다. 정보가 없으면 누락으로 알리고 다른 인계나 기억으로 채우지 않는다.
4. 부족한 맥락은 관련 경험·지식이 필요한 경우에만 조회한다. 원문 확인 요청은 호스트·작업·시점 등 알려진 단서를 session에 전달한다. 세션 digest 저장이나 원문 복사를 재개의 필수 단계로 두지 않는다.
5. 확인한 기존 포인터와 첫 행동, 미반영 내용·접근 문제를 반환한다. 실제 전달과 실행은 session 또는 담당 업무 기능에 맡긴다.

## 결과와 완료 판단

기존 기록 접근·반영 결과와 미결을 제공한다. 기록을 읽었다는 이유로 실제 세션 재개나 전체 작업 완료를 주장하지 않는다. 포인터가 깨졌거나 작업이 모호하면 영향받는 실행을 보류한다.
