# 설치 연결

저작 결과의 설치 또는 업데이트도 요청된 경우에만 읽는다.

## 수행 방법과 절차

1. 저작 결과와 검증 범위, 제품 및 승인 범위를 확인한다.
2. 제품이 제공하는 설치 CLI와 현재 등록 경로를 확인한다. 이 배포본에 별도 kit skill이 있다고 가정하지 않는다. Codex는 검증한 local marketplace를 native plugin 명령으로 등록하고, 기존 설치 및 전역 지침과의 충돌을 먼저 확인한다. 호스트 설정을 임의 형식으로 직접 편집하지 않는다.

## 연계와 의존

| 대상과 요청 | 입력 | 필요한 결과 | 의존과 부재 시 동작 |
|---|---|---|---|
| 제품의 설치 또는 업데이트 수단 | 검증한 산출 경로, 제품, 변경과 승인 범위 | 적용 결과와 미결 | 설치에 필수. 실제 CLI와 등록 경로를 확인할 수 없으면 저작 결과만 전달하고 설치 보류 |

## 결과와 완료 판단

저작 검증과 환경 적용을 구분해 보고한다. 저작 요청을 설치나 외부 전달 승인으로 확대하지 않는다.
