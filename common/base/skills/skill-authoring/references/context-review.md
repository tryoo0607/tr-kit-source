# 읽기량과 흐름 검수

skill 연결, reference 배치나 컨텍스트 읽기량을 바꾸는 저작/검수에 사용한다. 실제 모델의 선택을 고정하는 도구가 아니며 정적 비교와 실행 관측을 구분한다.

## 입력과 전제

변경 전후의 조립본, 동일한 사용자 요청과 입력 상태, 유효 요구/역할 경계, 비교할 읽기 목록을 받는다. 먼저 실제 파일을 보존한 기준본을 만들고 변경 후 새 출력에 조립한다. 작업 데이터와 동적 CLI guide, 호스트 주입은 측정 포함/제외를 명시한다.

## 수행 방법과 절차

1. 일반 요청, 도구 직접 요청, 실패/부재 상황과 가까운 비대상 요청을 고른다. 각 요청의 입력, 판단, 필요한 지침, 명령과 결과 확인을 따라간다. 파일명만 옮긴 경우와 실제 읽기 단계가 줄어든 경우를 구분한다.
2. 원본 버전, 경로/격리 정책, 승인과 hook 경계, 실패 처리, 입력/결과와 완료 기준이 보존됐는지 대조한다. 중요한 조건을 빼거나 이미 선택한 skill의 본문 일부만 센 것으로 절감 효과를 만들지 않는다. 사용법을 단순 복제한 wrapper도 분리 비용에 포함한다.
3. 읽기 목록을 파일과 선택할 제목 단위로 기록한다. SKILL.md는 전체를 센다. 모든 skill의 name/description 합계는 발견 비용으로 별도 비교한다. 중복 읽기, 불필요한 skill과 깨진 링크를 확인한다. CLI guide 등 미측정 부분을 0으로 측정했다고 보고하지 않는다.
4. 현재 skill 루트를 확인해 `python3 <skill-dir>/scripts/context_check.py --before <기준 조립본> --after <변경 조립본> --cases <JSON 목록>`으로 문자 수와 읽기 단계, 정확히 같은 읽기의 중복을 비교한다. Python/PyYAML이 필요하며 없으면 자동 설치하지 않고 수동 대조/도구 미실행을 구분한다. 이 도구는 선언한 목록의 정적 비교이며 실제 에이전트 경로를 추론하지 않는다. 제목/파일 부재는 실패다. 증가 허용은 이유와 범위를 명시하고 실제 검수로 타당성을 확인한다.
5. 정적 기준은 대표 경로의 합계와 중복, 발견 metadata가 증가하지 않는 것이다. 추가 요구로 증가가 필요한 경로는 별도 이유와 허용 범위를 명시한다. 동적 자료가 빠지면 전체 사용량 감소의 보증으로 표현하지 않는다. tokenizer가 없으면 문자 수만 보고하며 token 절감률로 환산하지 않는다.
6. 실제 자동 선택/읽기량까지 확인할 필요가 있고 실행 권한이 있으면 같은 호스트·모델·CLI 버전과 입력으로 전후 요청을 실행한다. 명시 호출, 자연어 호출, 비대상 요청을 함께 대조한다. 읽은 파일/절, 도구 반환 내용과 반복 조회를 로그에서 확인하고 관측된 범위만 기록한다. 노출된 token usage가 있더라도 전체 입력과 지침만의 비용을 혼동하지 않는다. 여러 실행의 최솟값만 골라 보장하지 않는다.

## 결과와 완료 판단

정적 비교 통과, 실제 실행 관측과 미실행을 구분해 보고한다. 고정 자료/읽기 목록의 비증가는 재현 가능한 범위의 검사 결과이며 임의 요청이나 모든 모델 실행을 보증하지 않는다. 동적 guide가 같다는 전제도 실제 버전/내용으로 확인해야 한다.

정적 결과와 함께 요구 보존, 중복 제거와 역할 경계의 대조 결과를 남긴다. 실제 자동 선택을 실행하지 않았다면 자연어 요청으로 발동 가능하다는 설명을 발동 성공 실측으로 표시하지 않는다. 스킬 검수 요청은 skill-authoring의 선택 대상으로 유지하고 코드/문서 일반 검수는 구분한다.

## 실패와 복구

비교 자료가 없거나 요청 조건이 달라지면 측정 불가로 알린다. 구조 변경으로 읽기 목록이 바뀌면 목록과 근거도 갱신한다. 불리한 결과를 감추기 위해 누락된 지침/출력이나 중복 조회를 제외하지 않는다. 도구 실행이나 모델 평가를 위해 미승인 설치/원격 동작을 추가하지 않는다.

## 예시

JSON 목록의 최소 형식은 다음과 같다. path는 각 조립본 기준 상대경로이며 reference의 일부만 읽는 경우 section에 실제 제목을 추가한다. 실행 시 조회하는 자료는 unmeasured에 기록한다.

```json
[{"name":"도구 요청","before":[{"path":"skills/example/SKILL.md"}],"after":[{"path":"skills/example/SKILL.md"}],"unmeasured":[]}]
```
