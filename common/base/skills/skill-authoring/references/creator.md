# 외부 creator 사용

일반 skill 작성, 수정, 검토에 공통 include된 OpenAI creator를 사용할 때 읽는다. 자체 기준은 본문에서 선택한 local-rules를 적용한다.

## 수행 방법과 절차

1. 아래 skill-creator 연결에 요청 동작, 대상과 확인한 입력을 전달해 일반 저작 절차를 적용한다.
2. 필요한 지원 자료와 도구는 대상 지침에 따라 선택한다. 원본의 절차를 복사하지 않고 자체 규격과 함께 적용한다. 제품 metadata는 요청에 필요한 경우만 추가하고 기존 설정을 재생성으로 덮지 않는다.
   script는 확인한 대상 skill 루트를 기준으로 실행한다. validator는 Python/PyYAML이 필요하고 initializer는 agents/openai.yaml을 생성한다. 이 metadata를 모든 제품의 필수 출력으로 취급하지 않는다.
3. 작성과 수정은 파일에 반영하고 검토는 차이와 근거를 전달한다. frontmatter, 이름과 폴더 일치, 공통 목차, 참조와 연결 계약을 대조한다. 고정 validator의 미지원 표준 필드는 삭제하지 않고 확인된 호환 검사 수단이나 수동 대조로 구분한다. 도구가 없으면 수동 대조와 도구 미실행을 구분하고 자동 설치하지 않는다.

## 연계와 의존

| 대상과 요청 | 입력 | 필요한 결과 | 의존과 부재 시 동작 |
|---|---|---|---|
| skill-creator (OpenAI): skill 작성, 수정 또는 검토 | 요청 동작, 대상 경로, 환경, 기존 자료, 적용할 자체 규칙 | 저작 결과 또는 검토 의견, 지원 도구와 검증 결과 | 이 경로에 필수. 선택 후 사용할 수 없게 되면 실행을 보류하고 본문의 선택 조건을 재확인 |

이 배포본의 [대상 SKILL.md](../../skill-creator/SKILL.md)로 진입해 요청 동작의 절차와 공통 제약을 적용한다. 내부 reference 선택은 대상 skill이 소유한다. 호스트 기본 제공본이나 다른 공급자로 조용히 교체하지 않는다. 연결은 지침 적용이며 별도 실행이나 자동 반환을 보장하지 않는다. 금지된 원본을 파일 읽기로 우회하지 않는다.

## 결과와 완료 판단

실제 사용한 원본과 지침, 변경 또는 검토 결과, 도구 검증과 미결을 전달한다. 구조나 형식 검사만으로 자동 발동과 다른 제품 실행 성공을 주장하지 않는다.
