# 기본 저작

기본 저작 경로로 선택된 일반 작성, 수정, 검토에 사용한다. 요청, 대상 경로, 환경과 기존 자료를 입력으로 받아 자체 절차로 수행한다. 자체 목차와 연결 기준은 본문에서 적용한 local-rules를 따른다. 경로 선택 조건과 다른 skill의 연결을 이 파일에서 판단하지 않는다.

## 수행 방법과 절차

1. 처리할 요청과 가까운 비대상 요청을 구분한다. 공통 적용한 local-rules의 선정 기준으로 재사용 범위와 자체로 작성할 차이를 확인한다. 새 skill은 실제 고유 작업이 있을 때 만든다.
2. 폴더와 name을 동일한 소문자 영숫자 및 하이픈 이름으로 정하고 SKILL.md에 name과 description frontmatter를 작성한다. description은 작업과 사용 조건을 짧게 구분한다.
3. 공통 판단과 필수 제약은 본문에, 조건부 상세는 필요한 reference에 둔다. 실제 재사용할 실행 로직만 scripts, 산출물에 쓰는 자료만 assets에 둔다. 빈 폴더나 별도 README를 자동 생성하지 않는다.
4. 입력, 수행 방법, 필요한 결과와 실패 대응을 실제 요청에 맞게 작성한다. 기존 승인 범위, 선택 설정과 지원 파일을 보존한다.
5. frontmatter와 참조, 호출 조건, 완료 기준을 대조한다. script를 변경했다면 의미 있는 실행 검증을 수행한다. 제품별 metadata나 hook 규격을 확인할 수 없으면 그 부분을 미결로 남긴다.

## 결과와 완료 판단

실제 수행한 절차와 검증 범위를 밝힌다. 실행하지 않은 도구 검증을 수행했다고 표시하지 않으며 실제 요청을 처리하기에 부족한 부분은 보류한다.
