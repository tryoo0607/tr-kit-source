# find-docs

## 목적과 역할 경계

- 기술명·정확한 버전·질문에 맞는 문서 근거와 확인 한계를 반환한다. 작업 계획·제품 판단·전체 조사 상태를 따로 관리하지 않는다.
- 공식 Context7 CLI에 직접 연결한다. 외부 find-docs SKILL.md를 복제하거나 그 `npx @latest` 절차를 치환한 사본으로 실행하지 않는다.

## 입력과 전제

- 실제 기술명, 요청 버전과 구체 질문, 기존 공식 근거를 받는다. 조회 문자열에 내부 코드·개인정보·비밀을 넣지 않는다.
- 명시 provider 선언과 현재 제품, kit root를 사용한다. 선택된 CLI 버전은 [도구 pin](../../scripts/dev-tools.toml)의 context7과 대조하며 불일치는 자동 갱신하지 않는다.

## 수행 방법과 절차

1. 아래 외부 연결 계약으로 `context7-cli`, 종류 cli의 설치 entry를 확인한다. 해당 CLI의 `--version`과 필요한 `library --help`·`docs --help`에서 실제 지원을 확인한다. 확인된 같은 버전 도움말은 재사용한다.
2. 명시한 정확한 library ID가 없으면 공식 `library` 조회로 대상을 확인한 뒤 필요한 `docs` 질의를 수행한다. 기술명·버전이 모호해 결과가 달라지면 확인한다. 명령·옵션·인자 형식을 도움말 없이 추측하지 않는다.
3. 반환 snippet만으로 원문 확인을 대체하지 않는다. 중요한 주장의 공식 문서·해당 버전 소스를 확인하고 원문 링크와 확인 범위를 답한다. 이미 충분한 정확한 버전 근거는 재조회하지 않는다.
4. 정확한 버전이 없거나 quota/인증/네트워크 오류면 그 한계를 밝힌다. 현재 허용된 공식 문서/소스 조회 수단이 있으면 해당 범위를 검증하고 Context7 조회 성공과 구분한다. 가까운 버전·학습 지식을 검증 완료로 대신하지 않는다. 반복 실패는 새 근거 없이 같은 질의를 계속하지 않는다.

## 연계와 의존

| 대상 | 전달 입력·필요 결과 | 필수 여부·부재 처리 |
| --- | --- | --- |
| provider `context7-cli` · 종류 cli. [공통 외부 연결](../../references/external-connection.md) | 기술·버전·질문/필요한 명령. 결과는 library ID·원문 포인터·확인 버전·제한 | Context7 조회에 필수. 부재 시 해당 조회 미실행. 공식 문서 직접 조회는 실제 수단·허용 범위를 확인하고 결과를 구분 |

## 제약과 주의점

- 조회 승인은 설치·업데이트·로그인·MCP 등록·새 서비스 설정 승인이 아니다. 기존 설치 CLI를 사용하며 부재를 `npx @latest` 다운로드로 해결하지 않는다.
- 검색 요약·source reputation 점수를 공식 원문 인증으로 취급하지 않는다. 사실·출처 주장·`[추론]`·미확인을 분리한다.

## 결과와 완료 판단

- 사용 도구/버전, 실제 library ID와 요청/확인 버전, 중요한 원문 근거와 미확인을 반환한다. 외부 전송한 질의와 실제 읽은 범위 안에서만 확인 완료를 판단한다.
