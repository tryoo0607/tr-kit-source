# 같은 대화의 인계와 재개

사용자 요청이나 확인된 사용량 신호로 같은 작업을 다음 세션에서 이어갈 때 사용한다. document가 기존 작업 정본과 관련 지식/경험을 대조해 인계 자료를 준비한다. 자체 session/round 저장 구조는 요구하지 않는다.

## 수행 방법과 절차

### 준비

1. 사용자 요청 또는 확인된 신호를 기준으로 준비한다. 체감 길이로 전환을 권하지 않고 준비 신호만으로 작업을 중단하지 않는다.
2. 작업 정체성과 수신 환경, 현재 기록 포인터를 확인한다. 기록 부재는 명시하고 새 호스트 ID를 새 작업으로 단정하지 않는다.
3. 아래 document 인계 준비 연결을 적용해 기록의 준비 결과와 미결을 받는다. 기록 내용을 별도 인계 정본으로 복사하지 않는다.
4. 수신 환경에서 결과 포인터와 필수 자료에 접근 가능한지 확인한다. 다른 호스트의 경로 대응과 전달 수단은 실제 확인한 것만 사용한다.
5. 승인된 수단으로 포인터와 첫 행동을 전달하거나 다음 회차에 넣을 문구를 제공한다. 실제 Orca 전달이 요청되면 아래 wrapper 연결을 적용한다. 문구 준비만이면 해당 연결을 읽지 않는다. 전달 확인 여부를 document의 기록 갱신 연결로 반환한다. clear/종료는 별도 승인된 호스트 수단으로만 실행한다. 준비 완료가 clear 실행을 뜻하지 않는다.

### 재개

1. 이어갈 작업과 지정 포인터를 확인하고 아래 document 인계받은 재개 연결을 적용한다. 새 세션이라는 이유로 새 작업 기록을 만들지 않는다.
2. document가 반환한 현재 상태와 요구/승인 확인 결과, 첫 행동 및 접근 문제를 실제 수신 환경에서 확인한다. 기록 충돌이나 미확인 제약에 의존하는 실행을 시작하지 않는다.
3. 짧은 재개 확인 후 허용된 첫 행동을 수행한다. 요구별 검증/기록 반영은 document 계약을 따르고 호스트에서 실제 이어졌는지를 확인한다.

## 연계와 의존

| 대상과 요청 | 입력 | 필요한 결과 | 의존과 부재 시 동작 |
|---|---|---|---|
| [orca-cli wrapper](../../orca-cli/SKILL.md): 기존 공간에 인계 내용 전달 | 확인한 호스트/공간 ID와 경로, 수신자, 포인터와 첫 행동, 같은 대화 재개 구분과 승인 범위 | 실제 수신자와 전달 receipt, 미결 | 실제 Orca 전달에만 필수. 부재/미지원은 전달 보류, 문구 준비는 계속 |
| document: 내부 인계 준비와 갱신 | 작업 정본 포인터 또는 부재, 미반영 요청과 수행 결과, 수신 환경 | 준비된 포인터/첫 행동, 유효 요구와 미완료 보존 확인, 필수 참조와 미결 | 기록 준비에 필수. 부재 시 갱신과 준비 완료 판정 보류 |
| document: 기존 작업 기록 갱신 | 작업 정본 포인터, 실제 전달 결과와 확인 범위 | 결과 반영 위치와 미결 | 전달 결과 저장에 필수. 부재 시 전달 사실과 저장 미완료를 구분 |
| document: 인계받은 작업 재개 | 작업 정본과 관련 세션 기록 포인터, 수신 환경과 요청 | 대조된 요구/상태, 현재 정본 포인터, 첫 행동, 미반영/접근 문제 | 기록 대조에 필수. 부재 시 확인 범위만 보고하고 재개 검증 보류 |

현재 환경에서 확인한 document 식별자의 SKILL.md로 진입해 요청별 분기와 공통 제약을 적용한다. 대상 내부 reference 경로를 직접 고정하지 않는다. 단순 재개에 인계 작성 지침을 추가하지 않는다.

## 분량과 읽기 범위

session 본문과 이 지침, 선택한 document 지침, 필수 기록/근거의 합계를 조회 비용으로 구분한다. 기록 분량과 선택 조회 규칙은 document가 소유한다. 같은 기록과 과거 인계를 연쇄 로드하거나 모든 context/wiki를 읽지 않는다. 정확 token 측정 없이 bytes를 token 비용으로 보고하지 않는다.

## 결과와 완료 판단

document 기록 준비, 실제 전달과 수신 환경의 재개 성공을 따로 보고한다. 자료 접근/요구와 상태 대조/첫 행동 확인 전 실제 재개 성공을 주장하지 않는다. 회차 종료와 대화 전체 목표 완료도 구분한다.

## 실패와 복구

포인터가 깨졌거나 대화 후보가 여러 개면 추측으로 선택하지 않는다. 접근 문제와 호스트 조작 미지원을 알리고 영향받는 실행을 보류한다. 강제 종료나 새 대화 생성으로 자동 확대하지 않는다.
