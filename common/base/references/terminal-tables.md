# 터미널 표

같은 기준으로 여러 항목을 비교할 때는 짧은 Markdown 표를 쓴다. 열에는 비교에 필요한 값만 두고, 긴 설명이나 근거 링크는 표 아래에 둔다. 좁은 화면에서 셀의 줄바꿈 때문에 항목과 값의 관계를 따라가기 어렵다면 사용자가 요청한 형식 안에서 열을 줄인다. 표가 필수가 아니면 항목별 목록도 사용할 수 있다.

[명시한 공식 외부 기능 연결](./external-connection.md)을 따라 현재 제품의 `claude-code-style` (종류 `skill`, 업스트림 `handsomeZR-netizen/claude-code-style-skill`)을 선택한다. 검수된 설치본에서 답변 형식 선택과 터미널 렌더링 지침을 적용한다. 이번 연결의 적용 범위는 답변의 표 표현이다. 사용자 지정 형식과 기존 공통 답변 기준을 우선한다.

설치본·검수 근거가 없으면 외부 검토는 미실행으로 두고 이 문서의 공통 표 기준을 적용한다. 실제 터미널에서 한글·영문 혼합 폭이나 줄바꿈을 관측하지 않았다면 렌더링을 검증했다고 보고하지 않는다.
