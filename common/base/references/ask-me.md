# Ask me

사용자와 시나리오를 하나씩 정하고, 합의가 전체 흐름에 미치는 영향을 대화에서 갱신한다. 대화에서 확인한 목적, 기존 결정과 사용자가 정정한 범위를 재사용한다.

## 인터뷰 연결

[명시한 공식 외부 기능 연결](./external-connection.md)로 현재 제품에서 Matt Pocock의 `grilling` (종류 `skill`, 업스트림 `mattpocock/skills`)을 선택한다. 이 기능은 [`grill-me`](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)가 위임하는 인터뷰 본체다. 각 제품에서 검수된 설치본에 진입하고 현재 시나리오, 합의, 질문 하나씩 진행한다는 요구를 전달한다.

설치본·선언·검수 근거가 없거나 제품 연결이 지원되지 않으면 이유를 짧게 알리고 인터뷰를 보류한다. 그때까지 확인한 시나리오와 미결은 대화에 남길 수 있다.

## 대화 진행

1. 모드에 진입한 첫 회신에 `Ask me 시작 · 시나리오를 하나씩 정리할게.`를 한 줄로 표시한다. 주제가 주어졌으면 대표 시나리오의 현재 흐름을 짧게 보여준다. 주제가 없으면 어떤 흐름을 논의할지 먼저 묻는다.
2. 지금 답하면 다음 흐름이 달라지는 결정 하나를 고른다. 자료나 기존 관례에서 확인할 수 있는 내용은 먼저 확인한다. 의미 있는 선택지가 있으면 각각 흐름이 어떻게 달라지는지 짧게 보여주고, 답을 기다린다.
3. 답을 받으면 영향을 받은 단계와 합의를 전체 흐름에 반영해 보여준다. 합의와 미결을 구분하고, 앞의 결정에 달린 다른 시나리오는 그 결정 뒤에 다룬다.
4. 흐름에 합의했거나 사용자가 “여기까지”처럼 종료를 요청하면 `Ask me 종료 · 합의한 흐름과 남은 결정을 정리했어.`를 한 줄로 표시한다. 합의한 내용과 남은 결정을 짧게 보여준다. 이어서 구현하거나 기록 파일을 만드는 일은 별도 요청에 따른다.
