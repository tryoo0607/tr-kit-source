# dive — 곁들이는 학습 큐레이터

**철학 = 비침습.** 작업은 빠르게 쳐내야 한다 — dive는 **막지 않고 얹는다.** 되묻는 게이트가 아니라, 곁에서 "이것도 있어, 알아?" 하고 호기심을 당기는 큐레이터다. 물면 파고들고, 안 물면 지나간다.

저장은 `knowledge`의 configured repository를 재사용한다. dive는 자기 data repository가 없고, 탐구 결과에 SRS 층만 얹는다. 저장하지 않는 설명·탐구는 profile 없이도 가능하다.

## 두 얼굴

### ① ambient 제안 (🤿) — opt-in

기본은 꺼져 있다. `public.features.dive_ambient=true`가 설정된 세션에서만 session-start context가 아래 규칙을 활성화한다.
작업 중 정말 관련 있고 알 가치가 있는 주제가 떠오르면 **응답 끝에 한 줄**:
```
🤿 dive — 지금 이거 하는데, 관련해서 [X]·[Y] 도 있어. 파볼까?
```
유저가 "그게 뭔데?"/"파보자" 하면 → ②로. 안 물면 그냥 넘어간다.

**⛔ 강한 스로틀** (💭 첨언 수준으로 엄격 — 남발하면 죽는다):
- **정말 관련+가치 있을 때만.** "이런 것도 있어요" 일반론 금지.
- **같은 주제 1회.** 무시당한 제안 다시 안 꺼낸다.
- **드물게.** 작업 흐름을 끊지 않는 빈도. 매 턴 X.
- **무시 가능.** 유저가 안 물면 조용히 넘어간다. 재촉 X.
- 한 번에 **1~2개 주제만**(메뉴 나열 금지).

### ② 파고들기 — 유저가 물었을 때
유저가 문 주제를 **깊이** 다룬다. 방식은 유저에 맞춘다:
- 기본은 **설명해준다**(빠른 이해 우선 — 이 스킬은 게이트가 아니다).
- 유저가 "직접 생각해볼게/힌트만" 하면 소크라테스식(질문·힌트 단계)으로 전환.
- 다 판 뒤: **재사용 앎이면 knowledge에 저장** 제안(knowledge skill 절차).

## 저장 — knowledge + SRS 층

판 결과는 **knowledge 노트**(기존 구조·절차 그대로). dive는 거기에 **복습 메타**만 얹는다:
```yaml
review:
  next: 2026-08-27      # 다음 복습일
  interval: 3           # 현재 간격(일) — 1→3→7→14→30
  score: 0              # 최근 자가평가 0~5 (SM-2 lite)
```
- knowledge 노트 스키마에 **optional `review:`** 필드(없으면 일반 노트, 있으면 복습 대상).
- 세션 시작 시(or "복습" 요청 시) **밀린 복습 항목을 능동회상으로 출제** — "노트 안 보고 핵심 말해봐" → 자가평가 → interval 갱신(맞으면 늘리고 틀리면 리셋).

## 탐구 로그 — surfaced vs explored

knowledge repository 안 단일 로그 파일(`_dive-log`, 첫 사용 시 생성, append):
```
2026-08-24 · surfaced: [sync.Map race, Go generics] · explored: [sync.Map race] · from: geodeonbar 작업
```
- 🤿로 **던진 주제**와 유저가 **판 주제**를 기록.

## 주간 리뷰

"이번 주 dive 어때?" 또는 주간 schedule 훅:
- **surfaced→explored 비율** = 던진 것 中 판 것. (죄책감 지표 아님 — 그냥 호기심 궤적)
- 밀린 SRS 복습 항목 몰아 출제.
- ⚠️ 비율 낮다고 탓하지 않는다. 관찰용.

## 학습과학 근거 (Dunlosky 2013)
파고들 때 얹으면 좋은 것: **능동회상**(노트 없이 말하기, 高효용) · **간격반복**(SRS, 高효용) · **정교화질문**("왜 참이지?") · **자기설명** · **Feynman**(나한테 가르쳐보기). 강제 아님 — 유저가 원할 때.

## 경계
- **저장·조회** → `knowledge`. 개인 정서 기록은 범위 밖이고, dive는 **호기심·학습 행위**만 다룬다.
- ambient 🤿 발동 규칙은 runtime profile이 켠 세션에만 주입한다. 상세·스로틀은 여기가 정본이다.
- 설계 = kit local-docs 의 `deepdive-skill-design` state 노트.
