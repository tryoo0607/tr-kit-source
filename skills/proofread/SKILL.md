# proofread

산문/문서를 검수한다. **출처·사실 검증이 최우선**(특히 자료조사). 코드=code-review, 이건 **텍스트**.

## ⭐ 최우선 — 출처·사실
- **주장·인용·수치·용어**에 근거 있나 확인. 링크·출처 유효한가.
- **추측이거나 확인 어려운 내용은 반드시 "추측/확인 필요"로 명시** — 사실인 척 넘기지 않는다. (내가 자료조사 검수에서 제일 중요하게 보는 것.)
- 자료조사(research) 결과면 특히 엄격히: 출처 없는 단정·과장·환각 의심을 짚는다.

## 검수 차원
| 차원 | 뭘 보나 |
|---|---|
| **출처·사실** ⭐ | 근거·링크·수치, **추측/미확인 플래그** |
| 오타·맞춤법 | 오타·띄어쓰기·맞춤법 |
| 문법·문장 | 비문·주술 호응·중복·장황 |
| 일관성 | 용어·표기·존댓말/반말·형식 통일 |
| 톤·대상 | **기본 전제 = 공유하는 문서**(남이 볼 수 있음). 확인용이라도 공유 톤 지향 |

## 출력 (code-review 형식 차용)
- severity 순: `등급 | 위치 | 문제 | 제안`. **출처·사실 문제는 상위 등급.**
- **추측/미확인은 별도로 모아** 명확히 표시("이 부분 확인 필요").
- **수정 적용은 제안 후 확인**(자동수정 X). 대량이면 요약.
- 한국어 위주(+영문 겸용).

## 경계
- 코드 리뷰=`review` / 이건 텍스트.
- 외부 문서 시스템에 올릴 글도 같은 검수 기준을 적용하되, 게시·전송은 별도 권한으로 다룬다.
- 상세 체크·한국어 흔한 오류 = `references/checklist.md`.
