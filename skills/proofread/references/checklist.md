# 검수 체크리스트 · 출력

## ⭐ 출처·사실 (최우선)
- 모든 **단정적 주장·수치·인용·고유명사**에 근거가 있나? 없으면 표시.
- **링크/출처**: 존재·유효·실제 그 내용을 뒷받침하나(엉뚱한 링크 아닌지).
- **추측/미확인 → 반드시 플래그**: "확인 필요", "출처 없음", "추정임" 으로 드러낸다. 사실처럼 단정 금지.
- **환각 의심**: 그럴듯하지만 확인 안 되는 API·버전·통계·인용은 의심 표시.
- 자료조사 결과면 특히 엄격 (1차 출처 우선, 없으면 그렇다고).

## 오타·맞춤법 (한국어 흔한 오류)
- 띄어쓰기(조사·의존명사·합성어), 자주 틀리는 것(되/돼, 안/않, 로서/로써, 든지/던지, 몇/맞춤법), 외래어 표기.
- 중복 조사·오탈자·자모 깨짐.

## 문법·문장
- 주술 호응, 비문, 이중 부정, 장황·중복 표현, 모호한 지시어(이것/그것).
- 한 문장 한 뜻(너무 긴 문장 분리 제안).

## 일관성
- 용어·표기 통일(같은 개념 다른 말 X), 존댓말/반말, 숫자·단위·날짜 형식, 제목 레벨·목록 스타일.

## 톤·대상
- **기본 전제 = 공유 문서**(남이 볼 수 있음). 확인용이라도 공유 가능한 톤.
- 과한 구어·비하·오해 소지 표현 짚기. 독자 지정되면 그에 맞춤.

## 출력 형식
```
[출처·사실] 위치 — <문제> → 제안 / ⚠️ 확인 필요
[major] 위치 — <문제> → 제안
[minor/nit] ...
```
- **출처·사실 문제를 최상단**에. 추측/미확인 항목은 별도 "⚠️ 확인 필요" 묶음.
- 제안은 구체적 수정안. **적용은 사용자 확인 후.**
- 문제 없으면 "없음". 좋은 점 한두 줄(과한 칭찬 X).
